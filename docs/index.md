## Overview

Chennai Academy Mind Profile AI is an AI-powered educational intelligence platform that helps students, parents, counsellors, and educational institutions understand a student's cognitive profile, learning behavior, personality, aptitude, interests, and career potential.

By combining psychometric assessments, learning analytics, multiple intelligence frameworks, and AI-driven recommendations, the platform generates personalised academic and career roadmaps to support confident educational decisions.

---

## Core Modules

### 1. Student Mind Profile
Builds a comprehensive profile including personality, aptitude, interests, learning style, emotional intelligence, study habits, strengths, and areas for improvement.

### 2. Career Recommendation Engine
Analyses interests, personality, aptitude, academic performance, and goals to suggest best careers, alternative careers, emerging careers, required skills, salary insights, and future demand.

### 3. Stream Selection Advisor
Helps students choose Science, Commerce, Arts, Diploma, or Skill-based programs based on assessment results.

### 4. Learning Style Analyzer
Identifies VARK learning preferences and recommends study techniques, revision strategies, memory methods, and time management.

### 5. Multiple Intelligence Assessment
Measures strengths across Linguistic, Logical, Musical, Spatial, Bodily, Interpersonal, Intrapersonal, and Naturalistic intelligences.

### 6. Psychometric Dashboard
Generates personality charts, aptitude scores, behaviour analysis, confidence index, decision-making style, and career readiness score.

### 7. Competitive Exam Advisor
Recommends JEE, NEET, CLAT, UPSC, CA Foundation, CUET, SAT, IELTS, TOEFL based on student profile.

### 8. Study Abroad Planner
Suggests countries, universities, courses, scholarships, eligibility, application timeline, and required exams.

### 9. Parent Dashboard
Parents can view student progress, strength reports, career recommendations, learning style insights, counsellor feedback, and action plans.

### 10. Counsellor Portal
Allows counsellors to manage students, schedule sessions, generate reports, compare assessments, track progress, and share recommendations.

### 11. AI Report Generator
Automatically creates professional PDF reports including personality profile, career matches, stream recommendations, learning style analysis, skill development plan, higher education roadmap, and career timeline.

### 12. Student Growth Tracker
Tracks progress over time with assessment history, academic milestones, goal completion, skill improvements, and career readiness score.

## Installation



## Usage

### Node.js CLI
```bash
npx mind-profile-ai "student-profile" Grade-12 85 82 88 78 90 80
```

### Python CLI
```bash
mind-profile-ai "student-profile" Grade-12 85 82 88 78 90 80
```

### Python Module
```bash
python -m mind_profile "student-profile" Grade-12 85 82 88 78 90 80
```
