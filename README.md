**AI Powered Student Intelligence & Career Guidance Platform**

Chennai Academy Mind Profile AI is an AI-powered educational intelligence platform that helps students, parents, counsellors, and educational institutions understand a student's cognitive profile, learning behavior, personality, aptitude, interests, and career potential. Built by [Chennai.Academy](https://chennai.academy).

## Features

- Student Mind Profile — comprehensive cognitive and personality profiling
- Career Recommendation Engine — AI-driven career pathway suggestions
- Stream Selection Advisor — Science, Commerce, Arts, Diploma guidance
- Learning Style Analyzer — Visual, Auditory, Reading, Kinesthetic assessment
- Multiple Intelligence Assessment — 8-dimension intelligence profiling
- Psychometric Dashboard — personality charts, aptitude scores, behaviour analysis
- Competitive Exam Advisor — JEE, NEET, CLAT, UPSC, CA, CUET, SAT, IELTS
- Study Abroad Planner — countries, universities, scholarships, timelines
- Parent Dashboard — student progress and strength reports
- Counsellor Portal — session management, reports, progress tracking
- AI Report Generator — automated professional PDF career reports
- Student Growth Tracker — assessment history and milestone tracking
- CLI support in Node.js and Python
- Benchmark dataset included (20 student mind profile cases)
- Lightweight, publish-ready, minimal dependencies

## Quick Start

### Node.js

```bash
npm install @chennai-academy/mind-profile-ai
npx mind-profile-ai "student-profile" Grade-12 85 82 88 78 90 80
```

### Python

```bash
pip install chennai-academy-mind-profile-ai
python -m mind_profile "student-profile" Grade-12 85 82 88 78 90 80
```
